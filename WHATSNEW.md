# What's new

## 5.1.0 (2026-11-14)

- **Modern FX graphics** – the client got a full effects layer (switch back to the classic look anytime in the launcher)
- **Single-port server:** Only one server port needed. All goes via the contact port (side effect: does not play anymore old recordings)
- Deathmatch highscores with join, pause and record popups (humans only).
- Duplicate nicks no longer block joining (`_#2`, `_#3`, … is appended).
- Metaservers addresses now come from `lib/metaserver.cfg`.
- Various small fixes and improvements


## 5.0.2 (2026-11-07)

- **First release on Github**
- **Voice chat** audio chat between TNG clients
- **Highscores:** popup and top ten lists, all kept per bot configuration.
- **Lag countermeasures:** jitter buffer for the client (experimental).
- **Launcher:** profile editor for the xpilotrc 
- **Ship shape editor** and ship shapes in selector
- **Windows:** cross-compiled bundle using MingGW
- Various small fixes and improvements
